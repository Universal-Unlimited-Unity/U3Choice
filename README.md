# U3Choice

U3Choice is a full-stack social platform with user profiles, friendships, real-time messaging, notifications, and search. The entire backend was designed and built by me, while the frontend was generated by AI and guided by the me.

## Tech Stack

- **Backend:** FastAPI, SQLAlchemy, PostgreSQL, Redis, Celery, Docker
- **Frontend:** Svelte 5, Vite
- **Auth:** JWT stored in cookies
- **Search:** PostgreSQL trigram search
- **Real-time:** WebSockets for notifications & messages

## Project Structure

```

├── backend/                 # Fully authored by me

```

## Features

- Auth: register, login, JWT refresh, logout, protected routes
- Profiles: view/edit your profile, avatar upload, change password / email / phone
- Friendships: follow / unfollow users
- Messages: real-time 1-1 chat via WebSocket (`/api/ws/messages`)
- Notifications: real-time alerts via WebSocket (`/api/ws/notifications`)
- Search: global search across users and posts via `/api/search?q=`
- Security: password hashing, CORS, token revocation

## Getting Started (Docker)

1. Clone the repo and enter the project.
2. Copy `.env.example` to `.env`, set the DB / Redis URLs and `TOKEN_KEY`.
3. Run the stack:
   ```bash
   docker-compose up --build
   ```

   - `database` → PostgreSQL on `:5432`
   - `redis` → Redis on `:6379`
   - `backend` → FastAPI on `:8000`
   - `frontend` → Vite dev server on `http://localhost:5173`

4. Visit `http://localhost:5173`.

## Run Without Docker

Backend:

```bash
cd backend
pip install -r requirements.txt
uvicorn api.main:app --reload
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

## API Overview

| Method | Endpoint                         | Description                |
| ------ | --------------------------------- | ------------------------------ |
| POST   | `/api/auth/register`             | Create an account          |
| POST   | `/api/auth/login`                | Login / get token               |
| POST   | `/api/auth/logout`               | Invalidate token            |
| PATCH   | `/api/users/{username}`            | Update current user profile   |
| POST   | `/api/friendships/follow`        | Follow a user              |
| POST   | `/api/friendships/unfollow`      | Unfollow a user              |
| GET    | `/api/messages`{`{id}`          | Get conversation with a user   |
| POST   | `/api/messages`                | Send a message             |
| GET    | `/api/search?q=`            | Search users/messages        |
| GET    | `/api/notifications`            | Get my notifications         |
| WS     | `/api/ws/notifications`          | Live notification stream      |
| WS     | `/api/ws/messages`          | Live messaging stream         |

## Configuration

- Backend reads settings from `backend/.env` (or environment).
- Frontend dev server: `:5173`.
- CORS allows `http://localhost:5173`.
- WebSocket routes: `/api/ws/notifications`, `/api/ws/messages`.
